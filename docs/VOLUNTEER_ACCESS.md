# Volunteer access

Owners/admins assign a volunteer to a group or activity for attendance management. Current staff role, active assignment and scope are checked on the server on reads, writes and receipt retries. Staff role changes revoke former assignments. Volunteers do not receive administrative People access. The removed points-awarding capability no longer exists in the schema, API or controls.

See [current workflows](redesign/WORKFLOWS.md) and [removal](REMOVAL.md). Separate cash capabilities belong to the future cash increment.
