# Optional session topics

Owner-authorized 30 October 2026. An activity retains its name (for example Sohbet); each session may have an independent **Topic or title (optional)**, such as Patience in everyday life. This is one plain-text field, not a different activity type or a replacement for the snapshotted activity name. It is optional, trimmed, limited to 160 characters and may be cleared. Omission by an older client preserves an existing topic during edits; blank explicitly clears it. Session creation and exact retries include the topic in their payload identity.

The existing create/edit session sheet owns the field. Preserve no autofocus, draft guards, failed-save input/request identity, one-hour end defaults, permission checks, optimistic versions, pricing/registration locks and the rule that session details are read-only after start. Owner/admin edit; authorized volunteers can read session context within their existing scope.

A provided topic leads session list/detail headings, attendance management and the dashboard preview; activity name remains secondary context. Activity next-session previews, registration and payment-only management also show the topic. Dates/times remain visible and accessible actions include enough context to distinguish sessions. Empty topics preserve existing activity-name/date presentation. No topic is inferred or backfilled from old session names. Session updates invalidate the organization's related queries so cached context and reporting refresh together.

The additive Drizzle migration is `0006_session_topic.sql`: a non-null text column defaulting to empty and a 160-character constraint. The guarded existing-database installer `scripts/session-topic-plan.mjs` locks the session table and compares all pre-existing session fields before/after, excluding only the new column, in one transaction. It neither changes historical activity/session names nor attendance, registrations or financial records. Fresh installation includes the generated migration automatically. Rollout evidence is in [infrastructure history](INFRASTRUCTURE.md).
