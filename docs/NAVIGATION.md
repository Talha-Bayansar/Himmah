# Navigation

Owner/admin launch opens `/workspace/:org/people/contacts`. People contains Contacts and Groups; profile collections have independent full-list routes. The shared fixed header has an organization switcher, notification shortcut and Profile. Primary navigation contains People, Activities and Manage. Volunteer launch opens Activities and does not expose administrative People/Manage links.

Manage contains organization details, staff, staff invitations and scoped attendance access. Profile contains language, installation, push-device preferences and sign-out. Futsal, rewards, challenges, engagement periods and participant-account routes have been deleted. Unknown old feature paths return not found. Old directory section bookmarks resolve to the canonical People entry.

Activities/attendance use canonical People contacts and groups. Registration, cash, Insights and learning remain later redesign increments; navigation does not pretend those pages are implemented.
