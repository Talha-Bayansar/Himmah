# Contacts and groups

The canonical directory is now People. Contacts are independent of staff accounts and support name-only records, own contact methods, multiple effective group memberships, directional/versioned relationships and separate communication responsibility.

The duplicate legacy directory is removed. Existing contact/group IDs and attendance references are retained through the scoped cutover. See [People implementation](redesign/PEOPLE_IMPLEMENTATION.md), [communication behavior](redesign/COMMUNICATION_STATUS.md) and [removal](REMOVAL.md).
